# Aditya Degree College Official Portal

## Run Locally
1. Open terminal in `F:\aditya-degree-college-website`
2. Run `npm install`
3. Run `npm run dev`
4. Public website opens at: `http://localhost:5173/`

## Hidden Admin Portal Access
- Secret Admin URL: `http://localhost:5173/aditya-admin-portal-2026`
- Admin ID: `adityaadmin@aditya.ac.in`
- Password: `Adityaadmin@1`
